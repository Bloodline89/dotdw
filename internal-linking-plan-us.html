How this plan was built

Every indexable page was embedded from its rendered content; the report scores each page against its closest semantic neighbours (0.80–1.00). We turn that into a linking plan in three steps:

1

Filter to real opportunities

Utility pages (bag, wishlist, order tracking) are removed. Parent↔child pairs (e.g. Women → Women’s Sandals) are set aside — breadcrumbs and navigation almost certainly link them already.

2

Prioritise by similarity × novelty

Cross-branch pairs (different site sections) with similarity ≥ 0.95 are the quick wins: strong topical match, unlikely to be linked through shared navigation today.

3

Suggest the anchor

Each target gets a descriptive anchor derived from its taxonomy (e.g. Women’s Outdoor Hiking & Trail) — keyword-relevant without being over-optimised. Adjust to fit the surrounding copy.

    Rollout plan

    Where the links should live

    • Category & collection pages (PLPs): a “Related categories” link module between the product grid and footer — 4–6 text links using the suggested anchors. One template component covers ~80% of this plan.
    • Sale pages: link each sale PLP to its full-price twin and back (e.g. Sale Women’s Sandals ↔ Women’s Sandals). These are the most reciprocal pairs in the dataset and pass authority into money pages year-round.
    • Stories & guides: in-copy contextual links from editorial to the matching PLPs. Note: guide pages rarely surface PLPs as semantic neighbours, so these need manual mapping — the explorer lists each guide’s nearest pages as a starting point.
    • Cross-gender collections: collection pages (Biom, Soft 7, Offroad, Citytray…) should link their men’s/women’s/outdoor counterparts — consistently top-scoring pairs.

    Guardrails

    • Cap added links at 4–6 per page. The plan lists up to 12 candidates per page so you can choose what fits; more links dilutes each one.
    • Don’t duplicate the mega-menu. Same-branch recommendations are marked — skip any already present in navigation on that template.
    • Keep anchors descriptive, not stuffed. Vary phrasing where several pages use the same target.
    • Re-crawl after rollout. Re-run the similarity report plus a crawl to confirm link depth and internal PageRank shifts toward the target PLPs.
    Source: Screaming Frog crawl of us.ecco.com with content embeddings — “Semantically Similar” report (17,580 scored pairs, 193 source pages, similarity range 0.80–1.00).
